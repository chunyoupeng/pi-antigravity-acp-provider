# v0.1.15 — Reliability, context safety and reasoning metadata

Requires Pi 1.1.x and Node.js >=22.19.0, unchanged from v0.1.14. Stable ACP protocol 1 / SDK 1.8.0 and the signed runtime catalog remain unchanged.

## Fixes

- Preserve MCP tool input constraints, including literal/falsy constants and supported numeric/collection bounds. Omit unrepresentable tools rather than silently widening their schemas. Bound depth, traversal work and UTF-8 output; handle cycles, shared graphs, custom validators, proxies/accessors and annotation defaults safely. Original call-time validation remains the authorization boundary (#42).
- Preserve the active request and its images outside truncatable context reconstruction. Retain active tool-loop call/result identities and fence untrusted history, with an independent bounded history/delta budget. Preserve current Pi transcript system sections and the existing 256 KiB instruction limit; avoid replaying requests already delivered to warm sessions (#42).
- Keep single-tier Gemini models marked as reasoning-capable, with only the server-advertised tier and exact ID. This fixes the misleading non-thinking warning for Argon Medium; it does not unlock Argon for ineligible accounts or invent Low/High variants (#42).
- Reuse saved macOS OAuth credentials when a refreshable file exists but the consumer keychain entry does not. Honor the effective child HOME/GEMINI_HOME/API-key environment, use consistent scoped paths for setup/inspection/logout, and label credential diagnostics as preflight expectations (#40).
- Harden cancellation, parked tool/permission cleanup, asynchronous initialization/shutdown, warm-session policy confirmation, continuation instruction updates and omitted-tool diagnostics. Prompt deadlines track progress rather than total duration, with finite stuck-work recovery. Preserve full system instructions and adapt child-only HTTP proxies while bypassing them for authenticated loopback MCP traffic (#39).
- Update the GitHub Actions Node setup action (#41).

## Validation and limits

- Clean install, typechecking and 254 enabled tests pass; eight opt-in official-runtime/live tests remain skipped in ordinary CI.
- Both supported Node CI lines validate checks, package contents, isolated packed installation and the full dependency audit.
- Local packed installation and full dependency audit pass with zero vulnerabilities. Release validation also exercises npm 12 packaging.
- An official ACP 1.3.0 metadata-only probe confirmed the advertised `gemini-4-argon-medium` ID and successful selection. No inference prompt was sent; catalog visibility is not proof of inference entitlement.
- Google currently lists Argon for AI Ultra and eligible Enterprise subscriptions, not AI Pro. No claim is made that this release fixes Google's plan gating, staged rollout or backend errors.
- Live Google inference, new-account OAuth, native-tool execution and cross-platform macOS/Windows qualification are not implied by synthetic tests. Default `yolo` permissions and automatic runtime updates remain unchanged; the provider is not a sandbox.
